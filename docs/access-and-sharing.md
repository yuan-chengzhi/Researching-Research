## 原始来源与项目说明分开

本仓库是研究地图，不是所有实验代码和数据的镜像。项目卡先说明问题、个人贡献、结果与边界，再给出来源；私有来源不能被理解成外部读者可以直接复核的公开证据。

Putnam 平台与固定实验报告仍为私有来源；本次只保留[项目经历与实验说明](../projects/putnam-2025.md)，不把它列为当前的公开代码展示入口，也不承诺赶在申请前公开。原始链接继续用于材料定位，访问仍需权限。

其他项目的访问状态按各条目现有记录理解，不代表本次逐一重新检查。`visibility_last_checked` 记录单独核对可见性的日期；`last_reviewed` 仍表示原研究内容的核对日期。公开状态更新不等于重新验证研究结果。

TacticWorld 的设计说明仍按原记录标注为私有来源；《集体加速》的原始报告尚未附入；部分 ContextSwarm 诊断和验收经过目前只有作者说明，待补精确 PR 或材料定位。项目说明可以公开阅读，并不要求其所有原始材料一并公开。

## 后续分享的边界

公开这份研究地图与公开原始团队仓库是两件事。分享其他材料前应分别审查团队稿件、日志、图表、合作者归属、匿名投稿安排与历史提交；不要因为当前首页已经整理好，就默认其他材料或完整 Git 历史也适合公开。没有必要为说明个人工作而公开全部原始运行数据。

不把临时授权链接、账号信息、服务地址或原始工作区路径复制到说明材料。本仓库的许可证也不替代被链接仓库或团队材料自身的使用与分享约定。
